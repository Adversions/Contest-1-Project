Snake Game



Compilation Instructions

1. Clone the repository
2. Download visual studio 2022 if not already installed
3. Download the Irvine32 library and save the path to it
4. Open the SnakeGame.sln project in visual studio
5. Open the properties of the project, click on the Linker section and add the path to the Additional LIbrary Directories section
6. Then click on the Microsoft Macro Assembler section and add the path to the Include Paths section 
7. compile and run the main.asm file
